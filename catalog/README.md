# catalog/: methods and guarantees, each with an assurance level

Every method in `methods/` has a manifest here, and CI rejects a method without one.
Levels are defined in [specs/protocols/assurance-levels.md](../specs/protocols/assurance-levels.md):
**verified** (gold standard: a wrong result cannot be accepted), **specified** (formal specification,
implementation unproved), **experimental** (evidence only).

| Folder | Contents |
| --- | --- |
| [methods/](methods/) | One TOML manifest per method: level, mode, Lean specification and correctness theorems, assumptions, conformance tests |
| [guarantees/](guarantees/) | Reusable claims built from methods. A guarantee's level is at most that of its weakest method |
| [contracts/](contracts/) | Composable trust contracts between parties (none yet) |

The table below is generated by `python3 tests/regression/check_catalog.py --write`.
